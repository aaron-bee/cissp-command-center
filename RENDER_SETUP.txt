WHAT CHANGED
------------
- Gunicorn production server.
- Starter Render service configuration.
- 1 GB persistent disk mounted at /var/data.
- SQLite production path: /var/data/cissp.db.
- Local SQLite path remains data/cissp.db.
- Login protection using Render environment variables.
- /health endpoint for Render health checks.
- Python pinned to 3.11.11.
- One Gunicorn worker to keep SQLite simple and safe for this single-user app.

RENDER
------
Create a NEW Blueprint from:
https://github.com/aaron-bee/cissp-command-center

Render will read render.yaml.

During initial Blueprint creation, enter:
DASHBOARD_USERNAME
DASHBOARD_PASSWORD

SECRET_KEY is generated automatically.

IMPORTANT: YOUR EXISTING LOCAL STUDY DATA
-----------------------------------------
The Render persistent disk starts empty.

The first Render deployment will create a new production cissp.db and seed
your February 2026 CISM historical attempt.

Your current local data\cissp.db is NOT automatically uploaded to Render.

If you want the current local question/study history copied to production,
do that migration before you begin using the Render copy as the main tracker.
